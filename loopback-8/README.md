# Comunicação Serial Assíncrona (UART) com Teste de Loopback

Projeto desenvolvido em C utilizando o framework ESP-IDF para compreender o funcionamento básico do periférico UART no ESP32 através da transmissão e recepção de dados em malha fechada (Loopback).
